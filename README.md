# Курсовой проект. Вариант 29: Мониторинг реактора (температура катализатора)

## 1. Условие задачи

Разработать программу для вычисления преобразованного значения показания датчика температуры катализатора (X) на основе кусочно-заданной функции Q(X).

**Параметры системы:**
| Параметр | Значение |
| :--- | :--- |
| **Параметр** | Температура катализатора (X) |
| **Единица измерения** | °C |
| **Диапазон X** | 20 ... 120 |
| **Нормальное состояние** | Штатный режим: 50–80 °C; значения вне диапазона рассматриваются как отклонение |
| **Количество измерений** | N = 50 |

## 2. Математическая модель

Преобразование показания датчика Q(X) задается следующей функцией:
*   Если X < 50, то `Q(X) = 3 * ln(X - 50 + 2) + 10`
*   Если 50 ≤ X ≤ 80, то `Q(X) = 2 * (X - 65) + 48`
*   Если X > 80, то `Q(X) = 5 * √(X - 80 + 1) + 58`

## 3. Алгоритм и блок-схема

### Алгоритм работы программы
1. **Начало**
2. Объявить переменную `X` для хранения значения температуры.
3. Запросить у пользователя ввод значения `X` (ввод с клавиатуры).
4. Проверить условие попадания температуры в первый диапазон:
   - Если `X < 50`, вычислить `Q(X) = 3 * log(X - 48) + 10` и перейти к шагу 7.
   - Иначе перейти к шагу 5.
5. Проверить условие попадания во второй диапазон:
   - Если `X <= 80`, вычислить `Q(X) = 2 * (X - 65) + 48` и перейти к шагу 7.
   - Иначе вычислить `Q(X) = 5 * sqrt(X - 79) + 58`.
6. Вывести на экран исходное значение `X` и вычисленное значение `Q(X)`.
7. **Конец**

# Система мониторинга температуры катализатора

## Постановка задачи

Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «температура катализатора» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.

### Входные данные:
- **Параметр X**: температура катализатора, измеряется в °C.
- **Диапазон X**: от 20 до 120 °C.
- **Количество измерений в выборке**: N = 50.
- **Ограничение (ОДЗ)**: для первого участка формулы аргумент логарифма должен быть больше нуля: \(X - 50 + 2 > 0 \Rightarrow X > 48\).

### Формула преобразования Q(X):

$$
Q(X) = 
\begin{cases} 
3 \ln(X - 50 + 2) + 10, & \text{при } X < 50 \\
2 (X - 65) + 48, & \text{при } 50 \le X \le 80 \\
5 \sqrt{X - 80 + 1} + 58, & \text{при } X > 80 
\end{cases}
$$

### Ручной расчет (Примеры):

1. **X = 49 °C** (меньше 50, попадает в 1-й интервал): 
   \(Q = 3 \cdot \ln(49 - 50 + 2) + 10 = 3 \cdot \ln(1) + 10 = 3 \cdot 0 + 10 = 10.00\)

2. **X = 71.60 °C** (в диапазоне 50–80, контрольный пример из задания): 
   \(Q = 2 \cdot (71.60 - 65) + 48 = 2 \cdot 6.6 + 48 = 13.2 + 48 = 61.20\)

3. **X = 85 °C** (больше 80, попадает в 3-й интервал): 
   \(Q = 5 \cdot \sqrt{85 - 80 + 1} + 58 = 5 \cdot \sqrt{6} + 58 \approx 5 \cdot 2.449 + 58 = 12.245 + 58 = 70.25\)
